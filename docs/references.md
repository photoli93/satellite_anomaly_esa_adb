# References

## Datasets

- **ESA Anomaly Dataset (ESA‑AD)**  
  Real telemetry from three ESA missions with curated anomaly annotations, released via Zenodo as the base dataset for ESA‑ADB.  
  Zenodo record: https://zenodo.org/records/12528696

- **ESA‑ADB Benchmark GitHub Repository**  
  Official benchmark code for an◊omaly detection in satellite telemetry, built on ESA‑AD. Contains splits, helpers and evaluation logic mirroring ESA operations.  
  GitHub: https://github.com/kplabs-pl/ESA-ADB

- **Spacecraft Anomaly Challenge on ESA Dataset (Kaggle)**  
  Kaggle competition using the ESA anomaly dataset, with ready‑to‑use data files and a leaderboard. Useful for sanity‑checking your preprocessing and baseline results.  
  Kaggle: https://www.kaggle.com/competitions/esa-adb-challenge

## Papers and benchmark descriptions

- **European Space Agency Benchmark for Anomaly Detection in Satellite Telemetry (arXiv)**  
  Main paper describing ESA‑ADB: motivation, dataset construction, missions, anomaly types, baseline models and evaluation metrics tailored to operations (eg : precision, lead time,..).  
  arXiv: https://arxiv.org/abs/2406.17826

- **European Space Agency Dataset and Benchmark for Anomaly Detection (OpenReview)**  
  Companion entry with additional benchmark details, experimental results and links to materials. Helpful for understanding the exact evaluation protocol.
  OpenReview: https://openreview.net/forum?id=FYEGPuUrpo

- **ESA Anomaly Dataset / ESA‑ADB Materials Page**  
  Landing page collecting materials for ESA‑ADB (slides, docs, links) as part of an ESA AI for Ground Segment initiative.  
  Materials: https://ai4gs.space-codev.org/esa-adb/materials/

- **ESA ESOC Announcement – Open Database of Satellite Anomalies**  
  Short article from ESOC explaining why ESA is releasing anomaly data, how it supports automation of operations and research in anomaly detection.  
  ESOC article: http://esoc.esa.int/esa-releases-building-block-open-database-satellite-anomalies
